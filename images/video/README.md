# Clips de video por página

Guarda aquí los clips propios de cada hero con el nombre exacto de su página:
`inicio.mp4`, `servicios.mp4`, `proyectos.mp4`, `nosotros.mp4`, `por-que.mp4`, `contacto.mp4`, `agenda.mp4`
(MP4 H.264, sin audio, 1920×1080, 6–10 s, ≤ 2.5 MB). Luego ejecuta `python3 tools/build/pages.py`.

Mientras un clip no exista, la página usa el segmento correspondiente del video de marca.
Prompts, especificaciones y comandos: `docs/VIDEO-PROMPTS.md`.
